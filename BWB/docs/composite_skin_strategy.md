# BWB 四区碳纤维/环氧蒙皮策略

蒙皮按上表面、下表面、前缘、后缘四区管理，每区独立设置铺层厚度和纤维角度。材料采用**已经浸渍并固化的双向织物碳纤维/环氧复合层**，以湿法铺层公开数据建立初始弹性模型。

这里的材料牌号和工艺是参考来源，不是用户零件的已知材料。初始参数用于比较分区、厚度和角度的影响，不代表完成强度设计，也不继承此前铝蒙皮试算的安全结论。飞行工况及其结果仍属于 `workspace/BWB/trials/` 临时试算；正式几何和建模代码归属 `BWB/`。

## 材料参考与参数来源

主要参考 NASA AGATE/NIAR 的 **3K Plain Weave Carbon / MGS 418 Wet Layup** 报告。该来源直接测试浸渍、固化后的复材，比裸碳纤维数据更接近“碳布浸 epoxy”的建模对象。[NIAR 湿法铺层报告，AGATE-WP3.3-033051-115](https://agate.niar.wichita.edu/Materials/WP3.3-033051-115.pdf)

| 参数 | 初始模型值 | 来源或假设 |
|---|---:|---|
| 经向、纬向弹性模量 `E1, E2` | 均为 47.2 GPa | 报告 RTD 轴向实测均值 6.85 Msi ≈ 47.23 GPa；两向相等是平衡织物近似 |
| 面内泊松比 `nu12` | 0.074 | 参考报告汇总表；明确作为初始假设，见下述条目差异 |
| 面内剪切模量 `G12` | 2.34 GPa | 报告 RTD 均值 0.34 Msi ≈ 2.344 GPa |
| 横向剪切模量 `G13, G23` | 均为 2.34 GPa | **未取得该材料相匹配的横剪测试数据；暂取等于 G12 的显式假设** |
| 固化复材密度 `rho` | 1350 kg/m³ | 报告拉伸/压缩板 1340–1370、剪切板 1320–1380 kg/m³；取范围内代表值 |
| 单织物层固化厚度 `t_ply` | 0.26416 mm | 报告归一化厚度 0.0104 in；1 in = 25.4 mm |

上述数据见报告第 24、26–28 页。汇总表的 RTD 泊松比为 0.074，而详细拉伸表相应条目为 0.055；不将两者的差异隐藏为确定的材料实测常数。当前使用 0.074，并可在 0.05–0.08 内检查敏感性。均衡近似下 `nu21=nu12`；若之后独立设置 `E1/E2`，应保持 `nu21=nu12*E2/E1`。

**RTD 的 dry 指固化试样的含水/环境条件，不指未浸渍的干碳布。** 报告中的 wet layup 是制造方式，RTD/ETW 等是试验环境，两者不是相反概念。报告具体试验板的纤维体积分数约 35–45%，孔隙也被测量；这些不是所有湿法铺层的固定值，也不是推荐的制造验收范围。

用于理解工艺差异的另一个独立例子是 Hexcel 8552/AS4 AGP193-PW：其平纹固化层厚 0.195 mm、密度 1570 kg/m³、纤维体积分数 55.29%，室温干态经/纬拉伸模量为 68/66 GPa。它使用另一种树脂与热压罐固化体系，不能直接替换本模型中的某一项参数并宣称仍代表同一材料。[Hexcel 8552 数据表，第 3、5 页](https://www.hexcel.com/wp-content/uploads/2025/12/HexPly_8552_eu_DataSheet1.pdf)

## Epoxy 与织物层如何计入模型

每个材料层代表“碳纤维织物 + 固化环氧”的整体有效性能，刚度、密度和厚度均包含 epoxy。不能再叠加一层完整树脂材料来补偿“浸渍”，否则会重复计算厚度、质量和刚度。只有明确存在额外的胶接层、富树脂层或涂层，并且有独立厚度依据时，才另建该层。

一个织物层本来就含两组近似正交的经纬纤维。织物角设为 `theta` 时，两组方向为 `theta` 与 `theta+90°`；这仍然是**一层**，不是两层各占完整厚度的单向材料。若以后改用单向带模拟经纬两束，需要重新建立等效方法，不能与当前织物层计数混用。

材料采用正交各向异性弹性描述。即使 `E1=E2`，面内剪切刚度也不是各向同性关系 `E/[2(1+nu)]`，因此整体旋转织物方向仍然会改变结构响应。横剪假设应随材料配置一起记录；若厚度、曲率或边缘受力使横剪显著，应增加相应测试或敏感性分析。

## 四区与角度约定

以当地弦向归一化坐标 `xi` 表示前缘到后缘的位置，前缘为 0、后缘为 1。配置中的 `leading_edge_chord_fraction=0.10`、`trailing_edge_chord_fraction=0.15` 都可修改，并要求两者大于零且总和小于 1。先分配前缘和后缘区，再把剩余蒙皮分为上、下表面，从而避免重复分配。

前缘比例的目标是当地前 10% 弦长，后缘比例的目标是当地后 15% 弦长；比例不是固定毫米宽度。脚本按单元中心的 `xi` 归区，边界落在既有网格线上，**不会在目标比例位置切开单元**。当前弦向 24 格，主体区域的实际前缘宽约 8.33%、后缘宽约 16.67%；目标与离散边界不同。若需要精确的 10%/15% 分界，应重建包含该分界的网格。四区完整覆盖和每单元唯一归属均检查；过窄参数导致区域消失时拒绝生成。

`theta=0°` 的参考方向定义为**局部从根部向翼梢的向外展向**，投影到各单元切平面后使用。上、下表面及两件镜像零件均遵循相同的物理方向约定；不能直接把全局坐标中的同一个角度值当作所有曲面上的相同铺层方向。正角方向还需与统一的壳法向共同定义，避免上下蒙皮法向差异引入符号歧义。

为使两件在任意指定角度下的纤维路径仍互为镜像，配置采用 `part_angle_sign={1:1, 2:-1}`：零件 1 的 PCOMP 角为 `theta`，零件 2 为 `-theta`。两件的 0° 都是各自的局部根部到翼梢方向；角度取负是在该参考系与统一壳法向约定下完成镜像，不是把零件 2 的展向改成向根部。该符号参数可配置，改变后应检查实际纤维方向而不只检查角度数值。

翼尖封口统一以当地弦向作为 0° 参考，并在清单中标记 `reference_kind=tip_chord`，因为展向在此封口上接近法向。封口的前后段归前后缘，中间段默认归上表面属性，亦可由 `tip_cap_middle_region` 改为下表面。这是四区模型对额外封口的明确约定。

每区可统一设置一个织物角，也可提供逐层角度列表。为了控制不必要的伸弯耦合，初始方案采用关于厚度中面对称的铺层；用户指定非对称序列时，应保留并报告相应耦合，而不是自动改回对称。

## 厚度参数与初始铺层

不需要把厚度选择作为开始建模的前置问题。先采用同一固化单层厚度和整数织物层数：

| 区域 | 初始层数 | 总厚度 |
|---|---:|---:|
| 上表面主体 | 4 | 1.05664 mm |
| 下表面主体 | 4 | 1.05664 mm |
| 前缘 | 6 | 1.58496 mm |
| 后缘 | 6 | 1.58496 mm |

前后缘比主体增加两层，是为了形成可参数化的初始区域差异，**不是文献证明本机翼必须如此铺层，也不是已经优化的结果**。边缘补强的连接、铺层终止和过渡工艺尚需在制造设计中确定。

当前将现有壳参考面视为层合板中面，`Z0=-h/2`，加厚向中面两侧对称扩展。若真实补强只铺在外侧，应在后续几何/铺层模型中表示相应偏置，不能把当前中面对称方案当作已复现单侧补强工艺。

配置可采用 `t_ply + ply_count`，或 `total_thickness + ply_count`：前者得到 `total_thickness=t_ply*ply_count`，后者得到等效 `t_ply=total_thickness/ply_count`。若三者同时提供，必须检查一致性，不能静默采用冲突值。还可按区域显式提供每层厚度，其总和就是区域总厚。

单层 0.26416 mm 是当前参考材料的参数起点，不是所有碳布的通用厚度。更换织物面密度、树脂含量或压实工艺时，应同时更新厚度与材料配置。用不同层数比较质量、位移与应变属于试算；不能仅因位移减小就宣布厚度合格。

## 输出与强度解释

输出各层经纬向应变、工程剪应变、材料坐标应力、结构位移，以及材料和铺层配置的来源。当前 PCOMP 面内输出位于**单元中心、每层厚度中点**；不是整个壳外表面或每层上下表面的峰值包络。层间 XZ/YZ 项位于该层上侧界面、采用单元材料坐标。层号沿壳法向从底到顶排列，不能与整个机翼的上/下蒙皮混为一谈。

原铝蒙皮试算中的 **200 MPa von Mises 屈服筛查不得沿用于碳纤维/环氧**。复材的拉伸、压缩、剪切及层间失效机理不同，必须取得与实际材料、铺层和环境匹配的 `Xt/Xc/Yt/Yc/S` 等数据后，选择并说明适用的失效准则。当前没有以文献中另一材料的强度填补未知值，也不将弹性应变计算等同于安全系数评定。

小变形线性结果仍需独立检查几何非线性、屈曲、层间剥离以及气动弹性稳定性。增加碳纤维材料与区域厚度并不会自动修复这些适用性限制。具体生成器入口、网格分区统计和当前版本验证结果应与实际实现一同记录。

## 在脚本中如何赋值与求解

入口配置为 [`../config/composite_skin.json`](../config/composite_skin.json)。四个区域的 `angle_deg` 是区域基准角，`ply_angles_deg` 是各层相对该基准角的偏角；实际铺层角还乘以零件的 `part_angle_sign`。例如基准 30°、偏角 `[0, 15, 15, 0]`，零件 1 的实际角为 `[30, 45, 45, 30]`。偏角列表省略时可用 `ply_count` 生成相同方向的若干层。

厚度使用米。可选 `ply_thickness_m`（统一单层厚度）、`ply_thicknesses_m`（逐层列表）或 `total_thickness_m`（总厚度均分）；重复给定时必须一致。脚本不把厚度锁定为某一种碳布规格。不同厚度的算例仍需检查壳理论、网格和实际材料工艺是否适用。

生成过程是：

1. 读取当前规则网格和行列布局，以 `xi` 完成四区互斥赋值；保留节点、连接关系及根部六自由度固定条件。
2. 用 `MAT8` 写入固化织物的材料轴常数；用 4 个 `PCOMP` 写入各区每层的材料、厚度、角度和输出请求。
3. 为每个壳定义局部 `CORD2R`，通过元素的整数 `MCID` 引用。改变纤维角度时，改变 PCOMP 角和相应变换刚度，而材料自身的 `E1/E2/G12` 不随全局朝向改值。
4. 按经典层合板关系记录每区 `A/B/D` 刚度矩阵和面密度。对称铺层的 `B` 接近零；非对称用户输入保留其耦合。一个织物层只计一次厚度和质量。
5. 沿用当前 11 个 CAERO1、590 个气动小面板、SPLINE1 和 W2GJ，加入飞况并运行 SOL144。两个零件各自固定根部、独立求解；这不是装配整机后的自由飞行配平。
6. 导出每个单元、每层的应力应变及所有结构节点的位移。独立核对 `p=q*Cp`、压力积分与根部反力/力矩平衡、材料本构关系、根部位移和变形量级，并检查非零气动弹性刚度及弹性升力增量。

求解卡采用完整显式铺层、`PCOMP SOUT=YES`、`PARAM,NOCOMPS,1` 和 `STRESS/STRAIN(PRINT,PLOT,SORT1,REAL,CENTER)=ALL`，不继承铝壳的 von Mises 或 FIBER 输出假定。依据为本机安装的 **Simcenter Nastran Quick Reference Guide，PCOMP 条目 16-129–16-133**，及 **User's Guide 24-41–24-42** 的层合板应力/应变输出位置说明。

在仓库根目录运行（求解器安装路径和许可证可用参数覆盖）：

```powershell
python -m BWB.scripts.run_composite_demo --output workspace/BWB/trials/composite_skin/new_baseline
python -m BWB.scripts.run_composite_demo --output workspace/BWB/trials/composite_skin/new_angle30 --angle-deg 30
```

只生成输入、不求解时：

```powershell
python -m BWB.scripts.build_composite_skin --output workspace/BWB/trials/composite_skin/new_inputs
```

目录必须使用新名字，避免覆盖已有求解证据。每次输出包含 `cases/part_N`、`runs/part_N`、`results/part_N` 和汇总 JSON。配置、脚本和测试入库；所有假设工况的输入、结果、图和诊断仍只保存在被 Git 忽略的 `workspace/BWB/trials/`。求解器原始错误/警告始终保留，数值检查通过不会自动将有诊断的运行标记为无错误。
