这是保留用于比较的首版自由网格。当前生成脚本已改为规则展向/弦向网格，最新模型和运行方法见 [结构化版本](../skin_structured/README.md)。本目录 `cad/` 仍是两版共用的只读 CAD 来源。

两个模型由 SolidWorks API 导出 Parasolid，再通过 Femap 2406 API 真实划分壳单元。用于理解 CAD → 表面网格 → 材料/厚度 → 根部约束 → Nastran 输入的流程。未运行求解器，也没有气动面板、SPLINE 或 SOL144 配平设置。

## 建模假设

- 全部计算量采用 m–N–kg–s。通过 `feGeometryInterface.ImportGeometryScale=1` 直接米制导入，避免沿用 Femap 默认 39.37 的几何导入倍率。
- 假设各向同性铝材：E=69 GPa、ν=0.33、ρ=2700 kg/m³；用于演示，不代表已确认材料牌号。
- PSHELL 厚度统一 1 mm，定义膜、弯曲和横向剪切材料。以 CAD 外表面作为零偏置壳参考面；没有提取真实蒙皮中面，也没有验证实体壁厚。
- 上下蒙皮与外边界参与网格，根部实体封口面（surface 1）排除，避免引入人工肋板。没有内部 rib、梁或体单元。
- 名义尺寸 20 mm，使用曲率及顶点尺寸调整，四边形为主，局部三角形。
- 假定宽端为安装根部：零件1 `z=0 m`、零件2 `z=1.56 m`。每件根部47个节点的平移及转动六自由度全部固定。这是演示安装条件，需要后续按实际连接确认。
- 节点合并容差设为 `1e-8 m` 并关闭自动容差，随原生模型保存。默认自动容差曾让局部上下蒙皮误连接，已修复并重新检查。
- `.bdf` 是 Femap 的静力分析格式结构导出（`SOL SESTATIC`），无外载、无求解结果，不是完成的 SOL144 输入。

## 检查结果与用途边界

每件均为一个连通分量；无零面积单元、缺失节点/材料/属性引用、近重合节点（1e-7 m 检查容差）、非流形边或相邻壳方向冲突。47条自由边全部在根部，所有根部节点均已六自由度固支。详细原始指标在每件的 `mesh_qa.json` 和 `build_report.json`。

仍有局部几何质量限制，不能据此宣称可用于可靠应变预测：

- 最差边长比约19，主要在狭窄后缘；最小角约0.61°。
- 局部四边形的简单对角三角形翘曲角最高约47°；这不是 Nastran 官方翘曲指标。
- 非常细小的后缘面 surface 14 未单独生成单元；离散网格在该局部发生简化。开口检查没有额外自由边，但不等于该细节被准确保留。
- Femap 默认 Nastran 质量检查返回空失败集，仅记录该 API 返回结果；它不替代上述独立几何检查和正式质量验收。

正式用于 SOL144/SHM 前，需要处理这些小特征、细化后缘/过渡区域、改善角度与翘曲，并做网格收敛；再确认蒙皮厚度、材料、参考面、根部连接和必要的内部支撑。约1.43 kg/件的蒙皮质量只是当前假设下的网格面积×厚度×密度估计。
