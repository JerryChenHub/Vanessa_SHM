# BWB：已求解的蒙皮应变演示

两个零件均完成实际 Simcenter Nastran 2406 SOL144 计算和结果恢复。按载荷平衡、简单理论估算、位移/转角与应力检查，输出适合作为当前流程演示。保留原始运行诊断，未宣称网格收敛、真实飞况验证或完整飞机强度验证。

## 飞况及模型

速度 20 m/s，密度 1.225 kg/m³，声速 340.3 m/s，Mach 0.05877，动压 245 Pa，迎角 2°，侧滑 0°。两件分别固定各自根部的 49 个节点，采用 E=69 GPa、ν=0.33、ρ=2700 kg/m³ 的 1 mm 铝蒙皮，无 rib/spar。只施加气动载荷，不计重力或机动惯性。

每件有 2940 个结构节点、2915 个壳单元、590 个气动面板。气动压力由线性亚声速势流模型求得，W2GJ 提供原始弯度/扭转，SPLINE1 传递结构位移和气动力；没有输入预设 CL，也没有进行 CFD。

## 实际结果

| 指标 | 零件 1 | 零件 2 |
|---|---:|---:|
| CAD +Y 向气动合力 | 6.551416 N | 6.551404 N |
| 对应单件参考面积的 C_Z | 0.1022904 | 0.1022902 |
| 最大结构位移模长 | 0.256681 mm | 0.256679 mm |
| 最大转角模长 | 0.0675645° | 0.0675641° |
| 两表面中最大主应变绝对值 | 22.39399 με | 22.39383 με |
| 中面最大主应变绝对值 | 12.47576 με | 12.47567 με |
| 从应变重建的最大 von Mises 应力 | 1.550919 MPa | 1.550908 MPa |

这里的向上合力是模型 CAD +Y / 气动参考系 +Z 方向；若严格换成风轴升力，需要再乘 cos(2°)，差约 0.061%。两件的最大应变差约 0.00069%，与近似镜像和源几何数值差异相符。它们是独立零件结果，不能简单宣称为已装配整翼的载荷。

`με = 10⁻⁶`。主应变为面内应变张量的特征值，计算时工程剪应变 γxy 除以 2；不是把剪应变直接作为张量分量。应变是壳单元中心、局部单元坐标的结果，没有节点平均。top/bottom 指壳法向正/负侧的 ±0.5 mm 纤维，不能直接当作机翼上/下蒙皮；mid 对分量取两面平均后重新计算主应变。

## 为什么认为量级合理

1. **气动力量级**：按孤立有限翼 AR≈2.897 的粗估升力斜率 `a=2πAR/(2+√(4+AR²))≈3.30/rad`，2° 下得到约 7.37 N；求解约 6.55 N，为其 0.889 倍。粗估未计后掠、弯度和翼梢耦合，仅用于排除数量级错误。
2. **载荷平衡**：由全部 590 个面板的压力×面积×法向积分，和根部 SPC 反力相加，残差分别约 4.55×10⁻⁷ / 1.48×10⁻⁷ N；关于各自根部的力矩残差小于 2.4×10⁻⁷ N·m。另从 49 个节点的反力及力臂重算核对。
3. **线性量级**：最大位移仅为参考展长的约 0.0295%，最大转角约 0.068°；最大应力约 1.55 MPa，明显低于本次额外假设的 200 MPa 屈服水平。屈服值用于演示筛查，没有指定实际铝合金牌号，也没有检查局部屈曲。
4. **应变粗估**：对 CAD 根部闭合薄壁截面积分，`I_x≈1.702×10⁻⁷ m⁴`。用根部力矩作非对称梁弯曲估计，轴向应变约 6.13 με；根部相邻壳的最大主应变约 8.72 με，同属个位至十位微应变量级。梁估计不包含局部壳弯曲、剪切和扭转，不能用来预测翼梢局部峰值。
5. **反馈与完整性**：零件 1 的刚性/弹性向上合力为 6.536920 / 6.551416 N，反馈约增加 0.22%；求解矩阵包含非零气动刚度。两件均完整恢复 2915×2 个壳纤维结果、2940 个结构位移，所有固定自由度为零。

## 保留的诊断与适用范围

求解均有 F06 `END OF JOB`、日志 `Analysis complete 0`，没有 Nastran fatal。日志仍包含一条 MKL DGEMM 参数 13 错误，启动器退出码为 1。针对**零件 1 的最终相同输入**启用 verbose 重跑，直接捕获 `m=0, n=1, k=3, ldc=0`，该调用的输出矩阵没有元素；零件 1 重跑的全部打印位移和应变与正式结果完全一致。零件 2 出现相同诊断并通过独立结果检查，没有另外做 verbose 复跑。详见 [诊断证据](runtime_diagnostic_review.json) 和 [求解记录](../../cases/sol144_demo/solver_notes.md)，未删除错误或改写为无错误状态。

因此自动导出与粗筛 JSON 仍保守保留 `diagnostic_only`，同时 `all_coarse_screens_pass=true`；[工程演示检查汇总](demo_review.json) 在保留这些诊断的条件下记录本次可用于演示的判断。此例不能作为忽略其他运行错误的通用规则。

薄后缘/翼尖封口处有 9 个壳单元超过默认几何检查阈值，未关闭或放宽检查。当前最大应变位于翼梢过渡附近的单元 2305，局部壳应变仍受 SPLINE 支撑、封口和网格密度影响；后续定量 SHM/强度使用需另外做这些敏感性与收敛检查。

```text
    │   ├── grid_displacements.csv  2940个结构节点的六自由度
    │   ├── solver_generated_aero_displacements.csv 气动内部点，单独保留
    │   ├── strain_summary.json     完整性、单位、来源、极值、诊断
    │   ├── reasonableness.json     气动力/反力、梁估算、应力量级

    │   ├── part_1_sol144_strain.modfem  内嵌实际OP2结果的Femap模型

```

直接用 Femap 打开对应 `.modfem`。默认显示向量 7071 **Plate Top MajorPrn Strain**，数值单位为无量纲应变，乘 10⁶ 得到 με；默认图的最大值约 16.87 με。上表 22.39 με 是两表面所有主应变中绝对值最大的值，位于 bottom 的压应变，二者不是同一个统计量。

Femap 结果已关闭重开验证、内嵌保存，不依赖临时 OP2 路径。原生模型仍不能代替含 W2GJ 的外部完整求解输入。重建命令见 [工况说明](../../cases/sol144_demo/README.md)。`workspace/BWB/sol144_demo/` 保留工作目录和失败/诊断尝试，不与 NASA_SHM 混放。
